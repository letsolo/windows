# Legacy Windows distribution placeholder

This repository is retired in favor of product-based releases. LoveBridgeVPN Windows installers and update feeds belong in [letsolo/lbv](https://github.com/letsolo/lbv), with independent `windows-v<version>` releases.

No application installers were published here during initialization. History is retained, but no new product releases should target this platform repository. Public casks belong in [letsolo/homebrew-tap](https://github.com/letsolo/homebrew-tap); private central CI owns builds and signing.

The repository has no App private key or publishing credential. Its last maintained workflow uses a read-only Actions token to verify Vapor-authored commits and repository privacy.
